# 0003. 対戦は締め切りを基準に、1回だけ評価する

- 状態: 採用（2026-10-27）

## 背景

確定した時刻を基準にスナップショットの区切りを決めると、遅れて届いた報告や日時を遡らせた報告によって、どの区切りでも処理されない対戦が出る。

## 決定

対戦の締め切り（マッチの作成時刻 + 締め切りの秒数）がスナップショットの区切りに入ったときに、その対戦を1回だけ評価する。並び順はマッチの作成時刻と id にする。

## 影響

- スナップショットをどこで区切っても、同じ結果になる。
- スナップショットへの反映は締め切りまで遅れる。クライアントは確定済みの対戦を暫定値として表示する。
