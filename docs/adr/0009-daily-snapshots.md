# 0009. スナップショットを GitHub Actions で毎日作る

- 状態: 一部置き換え（0011）

## 背景

0005 ではスナップショットを PR として置くことにした。誰かが手で作り続ける必要があり、運営がいなくなると止まる。fork して自分でアプリを動かす人も、同じ手間を負う。

## 決定

- `.github/workflows/snapshot.yml` で、毎日 05:00（日本時間）にスナップショットを作り、`snapshots/` に直接コミットする。
- シーズンが終わった日は最終スナップショットだけを作り、新しいシーズンの最初の分は翌日に作る。レート計算に関わる設定は、この1日の間に変える（0007）。
- 手での実行（`workflow_dispatch`）もできるようにする。手順は `docs/self-hosting.md` に書く。

## 影響

- fork したリポジトリでも、Actions を有効にすれば同じように積まれる。
- アプリはスナップショットを `raw.githubusercontent.com` から読むので、積むたびに配信し直す必要はない。
- PR での確認は経なくなる。ハッシュの連なりと `.ids.txt` で、あとから誰でも作り直して確かめられることは変わらない。
