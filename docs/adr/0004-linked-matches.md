# 0004. 対戦は、p2 の申し込みに結び付いたものだけを有効にする

- 状態: 採用（2026-10-27）

## 背景

マッチ成立のイベントは p1 が署名する。これだけで有効にすると、誰でも任意の相手を p2 にしたマッチを作り、相手に「未報告」の回数を付けられる。

## 決定

マッチは、p2 が署名して p1 の募集を指した申し込みに、成立待ちの時間内に応えたものだけを有効にする。1つの申し込みには1つの対戦だけを結び付ける。画面でも、結び付かない対戦は表示しない。

## 影響

- 第三者は他人を巻き込んだ対戦を作れない。
- レートの計算には申し込みのイベントも必要になる。
