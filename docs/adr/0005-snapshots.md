# 0005. レートのスナップショットを GitHub に置き、誰でも再計算できる形にする

- 状態: 採用（2026-10-27）

## 背景

公開リレーは古いイベントを消す。クライアントが起動のたびに全期間のイベントを読むのも重い。一方で、特定の誰かが計算した結果を信じるしかない形にはしたくない。

## 決定

- 全プレイヤーの状態をまとめたスナップショットを JSON で作り、PR として `snapshots/` に置く。
- スナップショットには前のスナップショットのハッシュ、使ったイベントの id の一覧とそのハッシュ、レート計算に関わる設定値のハッシュを入れる。
- 誰が生成しても同じバイト列になるよう、JSON の書き方と計算の順番を決める（`docs/protocol.md`）。
- クライアントはスナップショットとリレー一覧の取得元を設定で差し替えられるようにする。

## 影響

- Git の履歴とハッシュで、改ざんを検出できる（改ざんを不可能にするわけではない）。
- リポジトリがなくなっても、フォークした先で続けられる。
