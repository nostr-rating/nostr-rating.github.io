# 0015. 勝ち・負け・引き分けを報告した人の中止は数えない

- 状態: 採用（2026-11-04）
- 0002 の「中止と中止の組で確定する」に条件を足す。

## 背景

0002 では、それまでに出したすべての報告の中で噛み合う組が初めてそろった時点で確定する。報告の `created_at` は本人が決められるので、片方が中止を出していれば、もう片方は中止を日時を遡らせて出し、そろった結果より前に中止の組を作れる。

たとえば、A が中止を押し間違えたあと勝ちを送り、B が負けを送って確定したとする。B があとから中止の日時を A の中止より前にして出すと、中止の組が先にそろったことになり、結果が取り消される。

報告を受け取った時刻を第三者に記録してもらう方法も考えた。本プロジェクトで署名できるのは対戦の当事者2人だけで、どちらも時刻を遡らせられるので、当事者の署名で時刻を証明しても、この問題は防げない。中立の記録役を置くと、中央に寄る部分が増える。

## 決定

勝ち・負け・引き分けのどれかを報告した人の中止は、時刻を問わず数えない。引き分けのないゲームの引き分けの報告は、もともと使わないので、ここでも報告したことにしない。

片方のイベントを取り切れず、相手の最新の報告に合わせたとみなすとき（docs/spec.md「取得」）も、同じように、結果を報告した相手の中止は使わない。

画面では、勝ち・負け・引き分けを一度送ったあとは中止を選べなくする。

## 影響

- 遡らせた中止で、そろった結果を取り消せなくなる。
- 結果を押し間違えたあとで、双方が中止にし直すことはできなくなる。
- 中止の組がそろったあとでも、どちらかが勝ち・負け・引き分けを送ると、その人の中止は数えなくなる。相手が合わせなければ、締め切りで食い違いになる。変わるのはマナーの目安の分類（中止から食い違い）だけで、レートには入らない。
