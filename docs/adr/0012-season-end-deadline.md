# 0012. シーズンの終わりの直前も対戦でき、締め切りをシーズンの終わりで切る

- 状態: 採用（2026-11-04）
- 0007 の「締め切りがシーズンの終わりを越える対戦は数えず、クライアントもその間は新しい対戦を始めない」を置き換える。

## 背景

0007 では、締め切り（24時間）がシーズンの終わりを越える対戦を数えず、シーズンの最後の24時間は新しい対戦を始めなかった。双方が報告すれば対戦は数分で確定するのに、まる1日対戦できないのは、ふつうに遊んでいる人にとって代償が大きすぎる。

## 決定

- 対戦の締め切りを「マッチの作成から `report.deadlineSec` 後」と「作成した時刻のシーズンの終わり」の早いほうにする。
- 締め切りを過ぎたあとは、ほかの対戦と同じ決まりで扱う。組がそろわなければ未報告か食い違いになり、強制的に中止にはしない。
- シーズンの終わりの直前も新しい対戦を始められるようにする。締め切りがシーズンの終わりで切られる対戦では、対戦ルームにそのことを出す。

強制的に中止にする案もあった。マナーの目安の「中止」に数えると、相手が報告しなかっただけの人の回数も増える。数えなければ、負けそうな人が報告せずにシーズンの終わりを待つだけで、記録を残さずに済んでしまう。

## 影響

- シーズンの最後の24時間も対戦できる。その間の対戦は報告できる時間が短く、シーズンの終わりまでに双方が報告しなければ確定しない。
- シーズンの途中で入れても、すでに作ったスナップショットの結果は変わらない。締め切りの決め方が変わるのは作成から24時間以内にシーズンが終わる対戦だけで、その締め切りはシーズンの終わりなので、それより前のスナップショットでは処理していない。
