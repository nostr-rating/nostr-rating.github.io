# 0006. マッチの条件はクライアントで判定し、レート計算では確かめない

- 状態: 採用（2026-10-27）

## 背景

レート差、連戦、マナーの目安の条件をレート計算でも確かめるには、判定に使う状態を決定的に定める必要があり、計算が複雑になる。

## 決定

条件は双方のクライアントがそれぞれ判定する。マッチは双方が受け入れて初めて成立するので、片方が正規のクライアントなら条件は守られる。レート計算で確かめるのは、公開データだけで決まる「紐づけの有無」と「有効な対戦か」に限る。

## 影響

- 条件を破れるのは、双方が示し合わせたときだけになる。このなれ合いは連戦の重み付けで軽くする。
