# 0007. シーズンは一覧ではなく、起点と長さで決める

- 状態: 一部置き換え（0012）

## 背景

シーズンを一覧で定義すると、誰かが次のシーズンを足し忘れたときに、スナップショットの生成が止まり、クライアントの計算がずれていく。運営に依存しない仕組みとして、人の作業を前提にできない。

## 決定

- シーズンは起点の日時と「何か月ごとか」と時差で定義し、何期目かを計算で決める。
- 締め切りがシーズンの終わりを越える対戦は数えず、クライアントもその間は新しい対戦を始めない。
- シーズンが終わったら、最終スナップショットに成績のサマリーを残し、次のシーズンは全員が初期値から始める。

## 影響

- 誰も更新しなくても、シーズンは区切られて続く。
- シーズンの終わりの直前（締め切りの秒数の間）は、新しい対戦ができない。
- レート計算に関わる設定は、最終スナップショットと次のシーズンの最初のスナップショットの間でだけ変えられる。
