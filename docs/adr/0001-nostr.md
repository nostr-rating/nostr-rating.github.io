# 0001. 通信と署名に Nostr を使う

- 状態: 採用（2026-10-27）

## 背景

運営がいなくなっても続くレート戦にしたい。そのためには、対戦の募集や結果を中継する仕組みと、結果が本人のものだと確かめる仕組みを、特定のサーバーに頼らずに持つ必要がある。

## 決定

独自のリレーサーバーは作らず、Nostr（NIP-01 のイベント、公開リレー、secp256k1 の鍵）を使う。本人性は NIP-39 の外部アカウントの紐づけで示し、部屋 ID などは NIP-17 の暗号化 DM で送る。

## 影響

- 既存の公開リレーと、NIP-07 などの署名の仕組みをそのまま使える。
- リレーはイベントを永久には保持しないので、レートはスナップショットとして残す（0005）。
