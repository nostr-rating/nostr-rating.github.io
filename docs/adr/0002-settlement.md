# 0002. 結果は、噛み合う報告の組が初めてそろった時点で確定する

- 状態: 採用（2026-10-27）

## 背景

報告の `created_at` は本人が決められる。「双方の最新の報告」で判定すると、負けた側が日時を遡らせた報告を後から出すだけで、確定した結果を食い違いに変えられる。

## 決定

- 報告は置き換えのない通常のイベントにする。
- それまでに出したすべての報告の中で、噛み合う組（勝ちと負け、中止と中止）が初めてそろった時点で確定する。

## 影響

- 確定した結果はあとから足した報告で覆らない。
- 一度送った報告は取り消せない。押し間違えた報告に相手が合わせると、その内容で確定する。画面では送る前に確かめる。
