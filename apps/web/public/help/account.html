NOSTR-RATING ヘルプ

アカウントの守り方

Nostr-Rating には運営が管理するアカウントもパスワードもありません。あなたのアカウントはあなたの手元の端末だけで成り立っています。このページではその仕組みと、困ったときにどうすればよいかを説明します。

まず、これだけ

  1. はじめるときは「この端末で始める」を押すだけです。
  2. 表示される「復活の言葉」（12個の単語）を紙に書き写して、しまっておいてください。書き写さずに始めることもできますが、端末を全部失くしたときにアカウントを復元できなくなります。
  3. スマホとパソコンの両方で遊ぶなら、2台目も登録しておくと安心です。

普段の対戦で、鍵やパスワードを意識することはありません。

運営がいないということ

ふつうのサービスでは、運営のサーバーがあなたのアカウントを管理しています。パスワードを忘れたら、運営が復元してくれます。その代わり、運営のサーバーが破られると全員のアカウントが危なくなり、運営がやめればサービスも終わります。

Nostr-Rating はこの運営のサーバーを持ちません。アカウントを持っているのはあなたの端末なので、運営があなたのアカウントを復元することも、勝手に動かすこともできません。守るのはあなたの手元で、そのために手元で守りやすい作りにしてあります。

はじめてから対戦するまで

最初の登録と普段の対戦で、どこで何が起きるかを図にしました。色の付いた枠があなたの操作で、それ以外はアプリが自動で進めます。

5で投稿する文の見本

あなた @your_name

Verifying that I control the following Nostr public key: npub1q8x…7kfs

GitHub の場合は、同じ文を公開の Gist に貼ります。投稿や Gist は紐づけのあとも消さないでください。

はじめかた

  1. 「この端末で始める」を押します。
  2. 復活の言葉が表示されるので、紙に書き写します。
  3. 書き写せたかを確かめるため、12個のうち3つの単語を入力します。
1harbor2velvet3orbit4candle 5meadow6pilot7garlic8tunnel 9silver10anchor11maple12rhythm

上は表示のされ方の見本です。実際の言葉は、端末ごとに毎回ちがうものが作られます。

復活の言葉を書き写さずに始めることもできます。ただし、言葉は端末にも残らないので、あとから書き写すことはできません。端末を全部失くすと、アカウントは復元できません。

2台目を登録する

  1. 新しい端末で「すでにアカウントを持っている」を選ぶと、QR コードが表示されます。
  2. 登録済みの端末で設定の「QR を読み取る」を押し、その QR コードを読み取ります。続けて「この端末を追加」を押します。

この操作に、復活の言葉は使いません。

運営やアプリの URL が変わったとき

アカウントの本体は、アプリが動作している URL ではなく、Nostr のリレーに置かれた記録です。記録には登録した端末の一覧と、復活の言葉の印が載っています。運営がいなくなっても、アプリが動作している URL が変わっても、この記録はそのまま残ります。

一方で、端末の鍵は URL ごとに端末の中にしまわれ、別の URL のページからは読めません。そのため、同じスマホでも、新しい URL のページは別の端末として扱います。端末の一覧には、同じスマホが URL ごとに並びます。

場面変わることあなたがすること
運営がいなくなったアカウントとレートの記録は残り、レートの集計は誰でも作り直せます。アプリは今の URL でしばらく動くかもしれませんが、いつ止まるかは分かりません。止まったあとにその URL を別の人が手に入れると、その人のページは、その URL のページにしまった端末の鍵を使えます。誰かが別の URL でアプリを動かし始めたら、早めにそちらへ移ります（次の行の手順）。移ったら、古い URL の端末を取り消します。
アプリが動作している URL が変わった（古い URL も開ける）新しい URL のページは、別の端末になります。レートと成績はそのまま引き継がれます。2台目を登録するときと同じ手順で、古い URL のページから QR コードを読み取ります。終わったら、古い URL の端末を取り消します。
古い URL がもう開けない古い URL のページにしまった端末の鍵は使えなくなります。新しい URL のページで、復活の言葉を使って復元します。
自分でアプリのコピーを置いて使う自分のコピーも、別の端末の1つになります。ほかの人の端末の鍵は読めません。上の2つと同じです。

新しい URL が信用できないとき

新しい URL のページを登録すると、そのページはあなたとして対戦できます。悪いページだったときにできることは、端末を盗まれたときと同じです。

  • できること: 取り消すまでの間、あなたとして対戦の結果を出すこと（最大でおよそ1日分）。ほかの端末を取り消すこと。
  • できないこと: 別の URL のページにしまった端末の鍵を読むこと。復活の言葉なしに、アカウントを取り上げること。

気づいたら、ほかの端末から取り消すか、復活の言葉で復元します。どの URL に移っても、復活の言葉を普段のページに入力しないでください。

復活の言葉を作っていない場合、古い URL が開けなくなるとアカウントを移せません。X か GitHub を紐づけていれば、新しいアカウントで過去のシーズンの成績を引き継げます。

いちばん信用できるのは、あなた自身が動かす URL です。このアプリはソースコードが公開されていて、GitHub でコピー（fork）を作り、GitHub Pages で公開すれば、無料で自分の URL で動かせます。設定を変えなければ、ほかの人と同じリレーを使うので、別の URL で遊んでいる人ともそのまま対戦できます。ほかに誰もアプリを動かさなくなっても、あなたが動かしていれば、サービスを続けられます。

困ったとき

スマホを失くした・壊れた

ほかの登録済みの端末で「端末の一覧」を開き、失くした端末の「取り消す」を押します。拾った人がいても、その端末ではもうあなたとして対戦できません。

ほかに登録済みの端末がないときは、次の「全部の端末を失くした」の手順で復元します。

全部の端末を失くした

新しい端末でアプリを開き、「すでにアカウントを持っている」を選ぶと、QR コードが表示されます。別の端末（パソコンなど）で復活の道具を開き、12個の単語を入力してから、その QR コードを読み取ります。スマホしかないときは、下の「スマホで復活の道具を開く」を見てください。アカウントの鍵が全部取り替わり、新しい端末だけが使える状態になります。

このとき、新しい復活の言葉が表示されます。古い言葉はもう使えないので、新しい紙に書き写してください。

復活の道具はアプリのリポジトリのリリースからダウンロードする1つのファイル（nostr-rating-recovery.html）です。ダウンロードしたファイルをブラウザで開いて使います。入手先のリンクは、アプリの「すでにアカウントを持っている」の先の画面と、設定画面にもあります。

スマホで復活の道具を開く

スマホでは、ダウンロードしたファイルをブラウザで開くのに少し手間がかかります。手順は機種やバージョンによって違うことがあります。

Android の場合

  1. ファイル管理アプリ（Files by Google など）を開く。
  2. ダウンロードした nostr-rating-recovery.html をタップする。
  3. 開くアプリを聞かれたら、Chrome などのブラウザを選ぶ。

iPhone の場合

  1. 「ファイル」アプリを開き、ファイルを保存した場所（「このiPhone内」や「iCloud Drive」など）へ行く。
  2. nostr-rating-recovery.html を長押しするか、タップする。
  3. うまく開けないときは、共有ボタン（四角から上向きの矢印が出ているマーク）を押し、Safari か Chrome を選んで開く。

新しい端末と復活の道具を同じスマホで使うときは、画面の QR コードを読み取れません。アプリで「申請をコピー」を押し、復活の道具の「端末の申請」の欄に貼ってください。

知らない端末が一覧にある

アプリが「知らない端末が登録されました」と知らせたら、自分で登録した覚えがあるかを確かめてください。

  • 覚えがなければ、その端末を取り消します。
  • 自分の端末まで取り消されていたら、復活の言葉で復元します。復元すると、乗っ取った人が登録した端末はすべて使えなくなります。

乗っ取った人が出した対戦の結果のうち、取り消すまでの分（最大でおよそ1日分）は残ることがあります。

復活の言葉を失くした

端末が残っていれば、そのまま遊べます。ただし、復活の言葉は作り直せないので、端末を全部失くすとアカウントは復元できなくなります。

端末も残っていないときは、アカウントを復元できません。新しいアカウントを作り、以前と同じ X か GitHub のアカウントを紐づけると、過去のシーズンの成績を引き継げます。今のシーズンのレートは引き継げません。

復活の言葉の決まり

  • 紙に書きます。写真に撮ったり、スマホのメモやクラウドに保存したりしないでください。
  • 誰にも見せないでください。運営やサポートを名乗る人にも教えないでください。運営があなたの復活の言葉を尋ねることはありません。
  • 入力するのは、復活の道具だけです。普段対戦するページとは別に、ダウンロードして開くファイルです。万が一、普段のページが乗っ取られていても、アカウントを復元する操作を守るためです。
  • 心配なら、3枚に分けて別々の場所にしまうこともできます。3枚のうち2枚あれば復元できるので、1枚を失くしても困りません。分けられるのは、始めるときに言葉が表示された画面だけです。

よくある質問

復活の言葉は作らないといけませんか

作らなくても遊べます。作らずに始めるには、始めるときに「書き写さずに始める」を選びます。ただし、端末を全部失くしたときにアカウントを復元できません。レートはシーズンごとにリセットされるので、失くしたら作り直せばよいと考えるなら、作らないのも1つの選び方です。

運営に頼んで復元してもらえますか

できません。運営はあなたのアカウントを持っていないからです。運営が破られてもあなたのアカウントが無事なのは、このためです。

ブラウザのデータを消したらどうなりますか

その端末の鍵が消えます。ほかの登録済みの端末か、復活の言葉で復元できます。ブラウザによっては、しばらく開かないとデータが消えることがあるので、ホーム画面に追加しておくことをおすすめします。

X や GitHub の紐づけは何のためですか

1人で何個もアカウントを作れないようにするためです。アカウントを復元するためのものではありません。

紐づけのときに出した投稿は消さないでください。消すと紐づけが外れ、過去のシーズンの成績も引き継げなくなります。

（Nostr に詳しい人向け）署名アプリは使えますか

使えます。NIP-07 のブラウザ拡張と、NIP-46 のリモート署名（bunker）を、端末の鍵の1つとして登録できます。始めるときか、2台目を登録するときに「署名アプリを使う」を選んでください。Android の署名アプリは NIP-46 の bunker として使えるものなら登録できます。FROST で鍵を分けて持つ署名アプリも、NIP-07 か NIP-46 で使えるものなら同じように登録できます。

鍵はこのページの外にあるので、ページが乗っ取られても鍵そのものは持ち出されません。ただし、ページが開いている間に署名を頼まれること自体は防げません。署名のたびに確認を出す署名アプリなら、何に署名するかをその場で確かめられます。

登録した鍵はこのアカウントの端末の鍵の1つとして扱います。ほかの Nostr クライアントで使っている npub が、そのままこのアカウントになるわけではありません。

このアプリについて

Nostr-Rating は有志が作る非公式のサービスです。対応しているゲームの開発元・販売元とは関係ありません。ゲームの名前は、それぞれの権利者の商標です。

アプリが使っているソフトウェアのライセンスはライセンスの一覧にあります。
